RTO Admin – React + Vite + Bootstrap 5

1) npm install
2) npm run dev      -> open the link it prints (http://localhost:5173)

Where to edit:
  src/components/Sidebar.jsx   menu items (NAV list at the top)
  src/components/Layout.jsx    page titles in the top bar (TITLES list)
  src/pages/*.jsx              one file per screen – change text, numbers, table rows
  src/style.css                colours and layout (variables at the top)
