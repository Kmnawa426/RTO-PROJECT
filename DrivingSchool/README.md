# Driving School Portal: UI template

Static React + Vite template. Markup and styles only, with one hard-coded sample row per table written directly as JSX tags. No state, no API calls, no data files.

```bash
npm install
npm run dev
```

- `src/pages/`: Dashboard, Students, Schedule, Progress, Tests, Profile, Login, Register
- `src/components/`: Layout (sidebar + topbar), PageHeader, StatCard
- `src/index.css`: all styling
- `react-router-dom` is used only for page navigation.
